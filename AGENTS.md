# Public-site repository policy

This repository is deployed directly to a public website. Treat every tracked
file as public: it may be reachable from the live site and is visible in the
public Git history.

Do not add internal notes, decision records, research, drafts, prompts,
credentials, customer information, analytics exports, or other material that
is not intended for public viewing. Keep such material in an appropriate
private repository or workspace instead.

Only add content that is deliberately intended to be published as part of the
site. Before committing a new file, verify that both its content and its path
are safe to expose publicly.
